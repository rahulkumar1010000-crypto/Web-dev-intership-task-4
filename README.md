# Task 4: Simple Multi-Page Website

## Project Description
This project involved expanding the personal profile into a multi-page website. I implemented a navigational system linking 'Home', 'About', and 'Contact' pages while maintaining a consistent visual identity.

## Features
- **Relative Linking**: All pages are connected using relative paths for seamless navigation.
- **Unified UI**: Shared CSS and HTML structures (Header/Footer) ensure consistency across the site.
- **Active State**: The navigation bar highlights the current page for better UX.
- **File Organization**: Structured the project directory for better scalability.

## Tools Used
- VS Code
- Browser DevTools
